## 三网回程到底优化了什么，实测能跑多快

“三网优化”这个词被用烂了，具体到 GoMami 香港，指的是三条回程各走各家的精品节点：电信 CN2-GIA、联通 AS9929、移动 CMIN2。这三条线路在晚高峰的抗拥堵能力明显强于普通 163 骨干，也是它能开出这个价的主要理由。

2025 年 12 月有一份第三方测评（测试机由商家提供，测的是 HKG.Turin.Mini），数据可以直接拿来参考：

- 深圳电信 500Mbps 本地 → 香港：单线程约 475–478Mbps，基本跑满本地
- 济南联通 500Mbps → 香港：约 545–572Mbps，同样拉满
- 广东、武汉、宁波移动：上行被 QoS 得厉害，只有 33–50Mbps，下行正常；另一台 1Gbps 移动线路则跑到了 933Mbps

同一个测评里，机器本身的性能也很扎实：Geekbench 5 单核 2259、多核 4262，SysBench 单核 6173，fio 1M 块顺序读写 8.03 GB/s。

这里有个必须说清楚的现实：移动方向的上行 QoS 不是 GoMami 一家的毛病，在优化线路里相当常见。如果你的业务是大量上传（直播推流、备份回传），而且是移动宽带用户，这条线大概率不会让你满意；如果只是下载、看视频、普通建站访问，影响有限。电信和联通用户则可以放心一些。

## 几个藏在文档里、下单后才会遇到的问题

这些细节不会出现在套餐表里，但每一条都影响实际使用。

**流量是单向计费，只算 outbound。** 这一点相当关键，意味着标称 1TB 的套餐实际可用量比双向计费宽松不少。超出后带宽可能被限速，具体策略取决于套餐；流量额度在每个计费周期开始时重置。

**流量包不结转。** 补流量可以自助购买：100GB $6、500GB $30、1TB $60、2TB $120、5TB $300、10TB $600、20TB $1,200。但买的流量只在当期有效，不会留到下个月。长期不够用就该升级套餐，别指望靠加包省钱。

**换 IP 是 $5 一次，即时生效，旧 IP 立刻释放且不可恢复。** 换完记得同步改 DNS 记录，新 IP 完全生效还要几分钟。

**升降配要走工单，不能自助切换。** 想从 Nano 升到 Mini，得提交 ticket 等处理。

**部署通常 1–5 分钟自动完成。** 付款后会收到含 IP 和登录凭据的邮件。支持 Ubuntu 22.04/24.04、Debian 11/12、CentOS Stream 9、AlmaLinux 8/9、Windows Server 2019/2022，其他系统可以挂自定义 ISO。

**长期满负载会被判定为 noisy neighbor。** 持续高 CPU 占用影响同节点其他用户，可能被限制 CPU 性能。买来跑长时间满载任务的话要留意。

**默认给 1 个 IPv4。** 第三方实测里 IPv6 显示离线，官网套餐页也没有承诺 v6。需要 IPv6 的项目别默认它会有。

## 常见问题

**香港 VPS 需要备案吗？** 不需要。这是香港节点相对内地服务器最直接的优势，省掉整个备案流程。

**Pulse 和 Turin 线路一样吗？** 一样，都是 China Mainland Optimized Pro，三网回程都是 CN2-GIA / AS9929 / CMIN2。区别在硬件：Pulse 用 EPYC 7763（3.5GHz），Turin 用 EPYC 9575F（Zen 5，5GHz）配 PCIe Gen5 SSD 和 DDR5 6400 内存。对单核性能敏感的应用，Turin 的提升是实打实的。

**流量超了会怎样？** 可能被限速，具体看套餐。当期可以买流量包补，但包不结转。

**能装 Windows 吗？** Pulse 和 Turin 的 Pro 及以上套餐标注 Windows-ready，其他套餐需要确认。

**多久能拿到机器？** 付款后通常 1–5 分钟自动部署完成。
